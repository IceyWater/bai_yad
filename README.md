# BAI-yad

BAI-yad is a private subscription and recurring bill tracker built with Flutter. Add recurring expenses manually to see your estimated monthly and yearly costs, understand spending by category, and get local reminders before renewals.

The app does not connect to banks or require an account. Subscription data and profile settings are stored on the device, so the app can be used offline. BAI-yad is free and has no ads.

## Features

- Add, edit, search, filter, sort, and delete subscriptions and recurring bills.
- Track weekly, monthly, quarterly, twice-yearly, and yearly billing cycles.
- See normalized monthly or annual spending totals and a category breakdown.
- Review upcoming renewal dates and receive configurable local reminders.
- Flag rarely used subscriptions and see their potential savings.
- Keep profile and subscription data in on-device storage.

The interface uses Philippine peso formatting. Reminder delivery depends on granting notification permission and the device's notification settings.

## Requirements

- Flutter SDK `>=3.38.1`
- Dart SDK `^3.13.5` (included with Flutter)
- Android Studio or another configured Android toolchain for Android builds
- macOS with Xcode for iOS builds and simulator use

The SDK constraints are defined in [`pubspec.yaml`](pubspec.yaml). Check your installed versions with:

```sh
flutter --version
```

## Run the App

From the repository root, install dependencies:

```sh
flutter pub get
```

Connect an Android device, start an emulator, or open an iOS simulator, then check that Flutter can see it:

```sh
flutter devices
```

Run the app on the selected device:

```sh
flutter run
```

To target a specific device, pass its ID from `flutter devices`:

```sh
flutter run -d <device-id>
```

## Test and Analyze

Run the test suite and static analyzer from the repository root:

```sh
flutter test
flutter analyze
```

Tests cover billing and renewal calculations, currency formatting, reminders, persistence, state providers, and key app flows.

## Build

Create a release APK for Android:

```sh
flutter build apk --release
```

Create an Android App Bundle for Play Store distribution:

```sh
flutter build appbundle --release
```

On macOS with Xcode configured, build for iOS:

```sh
flutter build ios --release
```

The Android and iOS folders are the supported mobile targets. The other platform folders in the repository are generated by Flutter and are not currently project targets.

## Project Layout

- `lib/main.dart`: Flutter application entry point and app theme.
- `lib/features/subscriptions/`: subscription domain, local persistence, state management, reminders, and primary screens.
- `lib/features/onboarding/`: first-launch profile setup.
- `lib/core/`: shared theme, constants, and utilities.
- `test/`: unit, provider, repository, and widget tests.
